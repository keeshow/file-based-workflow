# 2026-10-23-01

上一版：[2026-10-21-04](../2026-10-21-04/workflow/AGENTS.md)。

## 修改原因

实际使用中，Agent 将“研究需要保留依据”“具有复用价值”作为自主生成专题笔记的理由，整理历史资料时新增多份摘要，超出用户意图并增加维护层次。

## 本版调整

- 保留必要 Debug 的自主维护权限；Note 仅由用户主动明确要求，或 Task 结束时 Agent 提议并获用户明确同意后生成。
- 不因复用价值、历史资料整理或分类新增专题笔记，不将普通研究改名生成 Debug；优先维护原文和导航。
- 允许在 Debug 中记录专题整理建议，不要求每个 Task 都询问，未授权时不提前创建草稿或占位文件。
- Note 列出实际参考的 Task、Debug、Handoff 或其他资料及参考内容；同步规则、示例和仓库简介。
