# 文件驱动的 Agent 开发工作流

当前版本：2026-10-21-03。

通过 `AGENTS.md` 约定协作规则，Task 管理当前任务和验收，Handoff 交接项目状态，Note 保存关键排查过程与可复用的技术结论。

## 1.工作流引入

将 [workflow/](workflow/) 内的全部框架复制到实际项目根目录即可使用，复制后 `AGENTS.md`、`handoff.md` 和 `docs/` 均位于项目根目录下。

已有同名文件时先比较、合并，保留项目原有规则、文档和状态，勿直接用框架文件覆盖已有内容。

## 2.框架简介

```text
workflow/                         # 当前版本的完整工作流框架
├── AGENTS.md                     # 通用协作、任务管理、验证与文档维护规范
├── handoff.md                    # 项目状态与交接快照，初始为空
└── docs/                         # 项目文档目录
    ├── README.md                 # 重要文档导航索引，预置通用目录入口
    ├── project-rules.md          # 项目专属约束，初始为空，由用户确定内容
    ├── tasks/                    # 独立任务的目标、实施进度、验收结果与遗留问题
    ├── notes/                    # 排查记录与专题笔记
    └── references/               # 原始参考资料及其来源、版本信息
```

`docs/README.md` 按主题或文档类型组织重要文档，每项包含相对链接和一句用途说明；文档新增、移动或删除时维护入口，不重复记录任务进度或验收结果。维护要求见 [AGENTS.md](workflow/AGENTS.md) 第 2、6 节。

框架另附 `.example` 写法示例，未在上图展开。示例文件保留供查阅，其中的项目、路径和结果不作为实际状态或验收证据。

各版本的完整框架快照与修改原因见 [.history/README.md](.history/README.md)。
