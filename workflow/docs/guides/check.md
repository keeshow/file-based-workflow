# 文档校验

> 首次运行 `docs/scripts/check-docs.py` 或结果异常时阅读。何时运行见 `AGENTS.md` 第 9 节，本文说明运行方式和结果处理。

## 运行

- 在项目根目录执行 `python docs/scripts/check-docs.py`；`python` 不可用时依次尝试 `python3`、`py -3`。
- `docs/project-rules.md` 的“文档校验”一节指定了命令时，按指定命令执行。
- 需要 Python 3.7 及以上版本，只使用标准库，不需要安装依赖。
- 脚本只读取文件，不修改任何内容；加 `--json` 时以 JSON 格式输出结果。

## 开关

开关写在 `docs/project-rules.md` 中，由用户决定：

```markdown
## 文档校验

- 状态：启用
- 命令：python docs/scripts/check-docs.py
```

- 没有该节或未写状态时视为启用；状态为“关闭”时不运行。
- “命令”可省略，省略时按上文顺序尝试。
- 因运行环境或脚本问题无法运行时，Agent 可以建议用户关闭校验或指定命令，不自行修改该节。

## 检查内容

| 代码 | 级别 | 内容 |
| --- | --- | --- |
| `TASK-NAME`、`NOTE-NAME` | 错误 | 文件名不符合 `NNN-名称.md`、`debug-NNN-主题.md`、`note-NNN-主题.md` |
| `TASK-DUP`、`NOTE-DUP` | 错误 | 编号重复；Debug 与 Note 共用一个编号序列 |
| `TASK-STATUS`、`DEBUG-STATUS` | 错误 | 缺少状态行，或状态值不在 `AGENTS.md` 规定的范围内 |
| `NOTE-AUTH` | 错误 | Note 缺少“授权：”行 |
| `TASK-INDEX`、`NOTE-INDEX` | 错误 | 文档未列入索引、索引重复列出，或索引中的状态与文档不一致 |
| `HANDOFF-STATUS` | 错误 | Handoff 中写的 Task 状态与 Task 文档不一致 |
| `LINK` | 错误 | `docs/` 下文档中的相对链接指向不存在的文件 |
| `TASK-DONE` | 警告 | `DONE` 的 Task 没有验收部分，或验收部分含“未通过”“未验证” |
| `SIZE` | 警告 | Task、Debug、Handoff 超过参考篇幅 |
| `SECRET` | 警告 | 疑似写入了密码、密钥或令牌 |
| `READ` | 警告 | 文件无法按 UTF-8 读取，已跳过 |

`.example` 示例文件、代码块和行内代码中的内容不参与检查。

## 结果处理

| 退出码 | 含义 | 处理 |
| --- | --- | --- |
| 0 | 通过 | 在报告中写明已通过 |
| 1 | 有错误 | 见下文 |
| 2 | 只有警告 | 逐条核对；需要整理的按对应写法说明处理，属于合理情况的在报告中说明 |
| 3 | 脚本无法完成检查 | 说明原因后照常结束任务；不修改脚本 |

处理错误时：

- 本次任务产生的问题，或属于自主维护范围的问题（如索引漏行、状态不一致、失效链接），修正后重新运行。
- 需要用户决定的问题（如已有文档改名、改编号）或无法判断的问题，在报告中列出，不自行处理。
- 本次任务之前已存在的问题，列出即可，不要求本次全部修正。

因缺少 Python 等运行环境而无法运行时，通知用户缺少什么及建议的安装方式；用户同意后可以安装，未经同意不安装或修改运行环境。

## 脚本依赖的写法

- Task 和 Debug 的状态行以“状态：”开头，紧跟状态值，如“状态：IN_PROGRESS（并发内存异常未解决）”“状态：排查中，根因未确认”。
- Note 开头有“授权：”行。
- 索引的每行用链接指向对应文档，并有一列只写状态值。
- Handoff 提到 Task 状态时，同一行写该 Task 的链接和状态值；一行涉及多个 Task 时不检查。
- 链接路径中的空格写成 `%20`，或用 `<>` 包住路径。
- 篇幅按非空白字符数估算，与实际字数略有出入。
