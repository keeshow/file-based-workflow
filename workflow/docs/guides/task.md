# Task 写法

> 创建或整理 Task 前阅读。必须遵守的规则见 `AGENTS.md` 第 4 节，本文说明具体写法。

## 内容

- Task 维护当前任务安排与验收依据，建议内容为：**状态、目标、范围/非目标、主要步骤及完成情况、关键决策、验收标准及结果、遗留问题、下一步和关联资料**。
- 约束按需记录，已有项目规则用链接引用。

## 步骤与验收

- 一个 Task 内按可检查的主要步骤管理实施进度，不按每轮对话、命令、函数或界面微调列项；仅在多个目标可独立验收时拆成多个 Task。
- 实施步骤的勾选只表示该步骤完成；验收按约定标准分别记录结果。
- 验收证据的记录方式见 [文档维护细则](maintenance.md)。
